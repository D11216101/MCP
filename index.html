8Alert 說明框

用於強調關鍵發現、風險警告或操作提示。左側 4px 色條區分嚴重等級，內部可包含 <strong> 標題與 .explain 補充說明段。

CRITICAL — 嚴重問題標題
這裡放補充說明，用較小字體（12px）以淺色呈現，給需要深入了解的讀者閱讀。
WARNING — 警告問題標題
同上，橘色左框代表警告等級，背景使用暖黃色系。
INFO — 資訊提示標題
藍色左框代表一般資訊或操作說明，背景使用淡藍色系。
Class左框色背景色使用情境
.alert.alert-red#B42318var(--critical-bg) #FEF3F2嚴重風險、立即需要處理的問題
.alert.alert-orange#B54708var(--warning-bg) #FFFAEB警告、需要關注但非立即危急的問題
.alert.alert-blue#2F6BFFvar(--ready-bg) #EFF8FF一般資訊、操作說明、備注提醒
子元素樣式說明
strong（直接子元素）font-weight: 700Alert 的主標題，必填
.explainfont-size: 15px / color: #555 / margin-top: 5px補充說明段，選填
9KV Grid 鍵值對列表

用於顯示案件摘要、設定參數等「欄位名稱 ＋ 值」形式的資料，比表格更緊湊。 容器使用 .kv-grid，每對資料由 .kv-label（左）和 .kv-value（右）組成。

案件編號#57 風險等級CRITICAL 被攻擊主機10.107.85.123 偵測時間範圍2026-08-17 ～ 2026-08-20
Class樣式說明
.kv-griddisplay: grid / grid-template-columns: 200px 1fr / gap: 6px 14px外層容器，定義兩欄比例
.kv-labelfont-size: 15px / color: var(--muted) #667085左欄：欄位名稱，淺灰色
.kv-valuefont-size: 15px / font-weight: 500右欄：對應的值，可嵌入 Badge 或 code
10Timeline 時間線

用於呈現依時間排列的事件序列（如攻擊鏈、操作歷程）。 外層 <ul class="timeline">，每個事件為 <li class="tl-item">， 內含左欄時間 + 圓點 (.tl-left) 與右欄說明 (.tl-right)。 右欄可選填解說框 (.tl-explain)。

11Two-col 雙欄對比

用於並排呈現兩組相關資料（如：安全監控 vs. 資料庫日誌，前後對比等）。 外層 .two-col 為 1fr 1fr 的 grid，每欄為 .col-box， 包含 .col-box-header 標題列、嵌套的 table，以及選填的 .col-note 底部備注。

Class說明
.two-col外層容器：display grid / grid-template-columns: 1fr 1fr / gap: 16px。RWD <800px 自動改為單欄。
.col-box單欄容器：1px 邊框、8px 圓角、overflow hidden

.col-note欄底備注：15px 灰色、#FAFBFD 底色、頂部分隔線，選填
